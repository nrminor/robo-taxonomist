# robo-taxonomist

An Effect-based TypeScript library for reconciling taxonomic metadata across databases and expressing relations between taxa and groups of taxa.

Early development; no taxonomy API yet.

## Development

Install [mise](https://mise.jdx.dev/) and Git, then review and trust the project configuration:

```sh
mise trust
mise bootstrap --only repos,tools,task
mise run check
```

Use `mise run check:fast` between edits. Run `mise tasks` to list the available commands.
